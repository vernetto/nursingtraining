# Appendix B. Differential Diagnosis Tables by Symptom

Each table lists **can't-miss (dangerous, time-sensitive)** diagnoses first, then **common** diagnoses, then **less common but important** ones, with **discriminating clues** and **first-line tests**. Use them to widen the differential, not to replace history, examination and clinical judgment. Probabilities depend on age, setting and context (chapter 69). Chapter references point to fuller discussion.

> **How to use.** (1) Write the one-liner. (2) Scan the can't-miss list and check each against the findings. (3) Scan the common list. (4) Use the clues to prioritise tests. (5) Re-enter the table if the course deviates.

---

## B1. Chest pain (ch. 11, 31, 65, 71)

| Category | Diagnosis | Discriminating clues | First tests |
|---|---|---|---|
| **Can't miss** | Acute coronary syndrome | Pressure, exertional or rest, radiation, sweating, dyspnoea, risk factors | ECG, serial hs-troponin |
| | Pulmonary embolism | Pleuritic, dyspnoea, tachycardia, DVT, risk factors | Wells/PERC, D-dimer, CTPA |
| | Aortic dissection | Abrupt tearing pain to back, BP/pulse differential, neurology | ADD-RS, CT angiography |
| | Tension pneumothorax | Dyspnoea, hypotension, absent breath sounds | Clinical; ultrasound |
| | Oesophageal rupture | Vomiting, subcutaneous emphysema, fever | CT with contrast |
| | Cardiac tamponade | Hypotension, JVP↑, muffled sounds | Echo |
| **Common** | Musculoskeletal (costochondritis) | Reproducible tenderness, movement-related | Clinical |
| | GERD/oesophagitis | Burning, postprandial, relief with antacids | Clinical, PPI trial |
| | Pericarditis | Pleuritic, positional, PR depression, friction rub | ECG, echo, CRP |
| | Pneumonia/pleurisy | Fever, cough, pleuritic | CXR |
| | Herpes zoster | Dermatomal pain, rash | Clinical |
| | Anxiety/panic | Hyperventilation, paraesthesia | Diagnosis of exclusion |
| **Less common** | Myocarditis, Takotsubo, aortic stenosis, HCM, peptic ulcer, biliary disease, pancreatitis, spontaneous pneumomediastinum, sickle cell crisis, cocaine-related vasospasm | | |

## B2. Dyspnoea (ch. 12, 31, 66, 71)

| Category | Diagnosis | Clues | Tests |
|---|---|---|---|
| **Can't miss** | Acute pulmonary oedema | Orthopnoea, crackles, JVP↑ | CXR/US, BNP, ECG |
| | PE | Pleuritic, DVT, tachycardia | Wells, CTPA |
| | Tension pneumothorax | Unilateral hyperresonance | Clinical |
| | Anaphylaxis/airway obstruction | Stridor, urticaria, trigger | Clinical |
| | Severe asthma/COPD exacerbation | Wheeze, silent chest, PEF | PEF, ABG |
| | ACS, arrhythmia, tamponade, sepsis, DKA (Kussmaul) | | ECG, gas |
| **Common** | Asthma, COPD, pneumonia, heart failure, anaemia, anxiety, deconditioning, obesity | | CXR, FBC, spirometry, BNP |
| **Less common** | ILD, pulmonary hypertension, pleural effusion, neuromuscular disease, thyrotoxicosis, pregnancy, metabolic acidosis, lung cancer | | CT, echo |

## B3. Cough (ch. 12, 46)

| Duration | Diagnoses |
|---|---|
| **Acute (<3 weeks)** | Viral URTI/bronchitis, pneumonia, asthma exacerbation, COVID-19/influenza, PE, aspiration, heart failure, pertussis |
| **Subacute (3–8 weeks)** | Post-infectious cough, pertussis, upper airway cough syndrome, asthma |
| **Chronic (>8 weeks)** | Upper airway cough syndrome, asthma/cough-variant asthma, GERD, ACE inhibitor, COPD/chronic bronchitis, bronchiectasis, TB, lung cancer, ILD, heart failure, OSA, chronic aspiration |
| **Red flags** | Haemoptysis, weight loss, smoker >40, dyspnoea, hoarseness, night sweats, fever, immunosuppression, abnormal CXR → CXR/CT, sputum, TB testing |

## B4. Haemoptysis (ch. 12, 71)

Can't miss: lung cancer, PE with infarct, massive bleeding (TB cavity, bronchiectasis, aspergilloma), vasculitis/Goodpasture, mitral stenosis with pulmonary oedema. Common: bronchitis, pneumonia, bronchiectasis. Others: TB, trauma, anticoagulants, AVM, cocaine, endometriosis (catamenial). Tests: CXR, CT chest, bronchoscopy, FBC, coagulation, urinalysis, ANCA/anti-GBM.

## B5. Palpitations (ch. 13, 65)

| Cause | Clues |
|---|---|
| **Arrhythmia**: AF, SVT, VT, PACs/PVCs, bradycardia/pauses | ECG, Holter; irregular, sudden onset/offset |
| **Structural**: valve disease, cardiomyopathy, HCM, congenital heart disease | Murmur, echo |
| **Systemic**: thyrotoxicosis, anaemia, fever, hypoglycaemia, phaeochromocytoma, hypovolaemia, pregnancy | TFT, FBC, glucose |
| **Drugs/substances**: caffeine, alcohol, nicotine, cocaine, amphetamines, decongestants, β-agonists, thyroxine | History |
| **Psychiatric**: anxiety, panic, somatisation | Exclusion |

## B6. Syncope and transient loss of consciousness (ch. 13, 36, 71)

| Group | Examples | Clues |
|---|---|---|
| **Cardiac (high risk)** | VT/VF, bradyarrhythmia, AV block, long QT, Brugada, HCM, aortic stenosis, PE, tamponade, aortic dissection | Exertional, no prodrome, palpitations, abnormal ECG, structural disease, family history |
| **Reflex** | Vasovagal, situational (micturition, cough), carotid sinus | Prodrome, triggers, standing, pain |
| **Orthostatic** | Volume depletion, drugs (antihypertensives), autonomic failure, bleeding | Postural BP drop |
| **Neurological** | Seizure, TIA/vertebrobasilar, migraine | Tongue biting, post-ictal confusion, focal signs |
| **Metabolic/other** | Hypoglycaemia, hypoxia, hyperventilation, psychogenic pseudosyncope | Glucose, SpO₂ |

| Category | Diagnosis | Clues | Tests |
|---|---|---|---|
| **Can't miss** | SAH | Thunderclap | CT ≤6 h, LP/CTA |
| | Meningitis/encephalitis | Fever, meningism, rash, altered consciousness | Antibiotics, LP |
| | GCA | Age >50, jaw claudication, scalp tenderness, ↑ESR | ESR/CRP, steroids, biopsy |
| | Intracranial mass/raised ICP | Morning headache, vomiting, papilloedema | MRI/CT |

| | Acute angle-closure glaucoma | Red painful eye, halos | Ophthalmology |

| **Common** | Tension-type, migraine, medication overuse, cluster, sinusitis, post-traumatic, cervicogenic, hypertension (rarely) | Pattern per ICHD-3 | Clinical |
| **Less common** | IIH, trigeminal neuralgia, temporal arteritis variants, Chiari, low-pressure headache | | |

## B8. Dizziness and vertigo (ch. 14, 51, 55)

| Type | Causes | Clues |
|---|---|---|
| **Vertigo (peripheral)** | BPPV, vestibular neuritis, Ménière's, labyrinthitis | Positional triggers, hearing loss, nystagmus unidirectional, positive Dix–Hallpike, head impulse abnormal |
| **Vertigo (central, can't miss)** | Posterior circulation stroke, cerebellar haemorrhage/tumour, MS, vestibular migraine | Ataxia, direction-changing nystagmus, normal head impulse (HINTS), diplopia, dysarthria |
| **Presyncope** | Orthostatic hypotension, arrhythmia, anaemia, drugs, aortic stenosis | Standing, palpitations |
| **Disequilibrium** | Neuropathy, Parkinsonism, visual impairment, normal-pressure hydrocephalus | Gait |
| **Non-specific** | Anxiety, hyperventilation, hypoglycaemia, drugs | |

## B9. Acute abdominal pain (ch. 15, 47, 71)

| Region | Can't miss | Common |
|---|---|---|
| **Epigastric** | MI, perforated ulcer, pancreatitis, AAA, mesenteric ischaemia | Dyspepsia/ulcer, gastritis, GERD, biliary colic |
| **RUQ** | Cholangitis, cholecystitis, hepatic abscess, Fitz-Hugh–Curtis | Biliary colic, hepatitis, hepatic congestion, pneumonia |
| **LUQ** | Splenic infarct/rupture, MI | Gastritis, pancreatitis, pyelonephritis |
| **Periumbilical** | Early appendicitis, SBO, mesenteric ischaemia, AAA | Gastroenteritis, constipation |
| **RIF** | Appendicitis, ectopic pregnancy, ovarian torsion, testicular torsion (referred), perforated caecal cancer | Mesenteric adenitis, Crohn's, ovarian cyst, UTI, hernia |
| **LIF** | Diverticulitis, ectopic, sigmoid volvulus, ischaemic colitis | Constipation, IBD, UTI |
| **Flank/back** | AAA/dissection, pyelonephritis, renal colic | Musculoskeletal, renal stones |
| **Diffuse** | Peritonitis, bowel obstruction, mesenteric ischaemia, DKA, perforation | Gastroenteritis, IBS, constipation |
| **Referred/systemic** | MI, pneumonia, DKA, adrenal crisis, porphyria, sickle crisis, lead poisoning | |

Tests: pregnancy test (women), FBC, CRP, U&E, LFT, lipase, glucose/ketones, lactate, urinalysis, ECG, erect CXR, ultrasound, CT.

## B10. Nausea and vomiting (ch. 15, 47)

Acute: gastroenteritis, drugs (opioids, chemo, antibiotics), pregnancy, DKA, raised ICP, MI (inferior), obstruction, pancreatitis, cholecystitis, appendicitis, meningitis, toxins, labyrinthine. Chronic: GERD, gastroparesis, cannabinoid hyperemesis, functional, pregnancy, uraemia, hypercalcaemia, Addison's, psychogenic, cyclic vomiting. Red flags: bilious or faecal vomiting, haematemesis, severe pain, neurological signs, dehydration, projectile in infants.

## B11. Diarrhoea (ch. 15, 47)

| Type | Causes |
|---|---|
| **Acute infectious** | Viral (norovirus, rotavirus), bacterial (Campylobacter, Salmonella, Shigella, E. coli, C. difficile), parasitic (Giardia, amoebiasis) |
| **Non-infectious acute** | Drugs (antibiotics, laxatives, metformin, magnesium), food intolerance, ischaemic colitis |
| **Chronic >4 weeks** | IBS, IBD, coeliac, microscopic colitis, bile acid diarrhoea, pancreatic insufficiency, hyperthyroidism, colorectal cancer, drugs, overflow, diabetes, carcinoid, HIV, lactose intolerance |
| **Red flags** | Blood, weight loss, nocturnal, age >50, family history of cancer/IBD, anaemia, fever, recent antibiotics/hospitalisation, immunosuppression |

## B12. Constipation (ch. 15, 47)

Primary (slow transit, outlet dysfunction), secondary: drugs (opioids, anticholinergics, calcium channel blockers, iron), hypothyroidism, hypercalcaemia, hypokalaemia, diabetes, Parkinson's, spinal cord disease, depression, pregnancy, colorectal cancer, stricture. Red flags: age >50 new onset, rectal bleeding, weight loss, anaemia, family history, obstruction signs.

## B13. Gastrointestinal bleeding (ch. 15, 47, 71)

Upper: peptic ulcer, erosive gastritis/oesophagitis, varices, Mallory–Weiss, malignancy, Dieulafoy, angiodysplasia. Lower: diverticular disease, haemorrhoids, colitis (ischaemic, infectious, IBD), angiodysplasia, polyps/cancer, anal fissure. Brisk upper bleed can present as haematochezia with instability. Tests: Glasgow-Blatchford, Hb, urea, coagulation, endoscopy/colonoscopy, CT angiography.

## B14. Jaundice (ch. 15, 47, 71)

Pre-hepatic: haemolysis, Gilbert. Hepatic: viral hepatitis, alcohol, drugs, autoimmune, cirrhosis, Wilson, ischaemic, pregnancy-related. Post-hepatic: gallstones/cholangitis, pancreatic cancer, cholangiocarcinoma, PSC/PBC, strictures. Can't miss: cholangitis, acute liver failure, haemolytic crisis, HELLP.

## B15. Dysphagia (ch. 15, 47)

Oropharyngeal: stroke, Parkinson's, myasthenia, ALS, Zenker's, head and neck cancer, post-radiation. Oesophageal: GERD stricture, cancer, eosinophilic oesophagitis, achalasia, diffuse spasm, rings/webs, scleroderma, extrinsic compression (aortic aneurysm, mediastinal mass). Red flags: progressive solid dysphagia, weight loss, odynophagia, anaemia, age >55 → urgent endoscopy.

## B16. Fever (ch. 16, 53, 71)

| Category | Examples |
|---|---|
| **Bacterial emergencies** | Sepsis (any source), meningitis, endocarditis, necrotising fasciitis, toxic shock, cholangitis, pyelonephritis with obstruction, spinal epidural abscess, septic arthritis, neutropenic sepsis |
| **Viral** | Influenza, COVID-19, EBV, CMV, HIV seroconversion, dengue, hepatitis, VHF |
| **Tropical/travel** | Malaria, typhoid, dengue, rickettsia, leptospirosis, amoebic liver abscess |
| **Non-infectious** | Malignancy (lymphoma, RCC, leukaemia), vasculitis (GCA), SLE, Still's, sarcoid, drug fever, PE, thyroiditis, adrenal crisis, hyperthyroid storm, factitious |
| **FUO (>3 weeks)** | Infection (TB, abscess, endocarditis), inflammatory, malignancy, miscellaneous |

## B17. Weight loss (ch. 16, 72)

Intentional vs unintentional. Causes: malignancy, depression, hyperthyroidism, diabetes, malabsorption (coeliac, pancreatic), chronic infection (TB, HIV), COPD/HF cachexia, chronic kidney/liver disease, dementia, drugs, alcohol, eating disorders, poor dentition/dysphagia, poverty. Baseline tests: FBC, CRP, U&E, LFT, calcium, TSH, glucose, HbA1c, ferritin, coeliac serology, HIV, urinalysis, CXR ± CT.

## B18. Fatigue (ch. 16)

Common: depression/anxiety, sleep disorders (OSA), anaemia (iron deficiency), hypothyroidism, diabetes, medications, post-viral, lifestyle. Others: cancer, chronic infection, heart failure, COPD, CKD, liver disease, autoimmune, Addison's, coeliac, hypercalcaemia, chronic fatigue syndrome/ME, fibromyalgia, pregnancy. Red flags: weight loss, fever, night sweats, lymphadenopathy, focal neurology.

## B19. Lymphadenopathy (ch. 50)

Localised: infection (EBV, TB, cat-scratch, skin), lymphoma, metastases, sarcoid. Generalised: viral (EBV, CMV, HIV), TB, syphilis, toxoplasmosis, lymphoma/leukaemia, SLE, RA, sarcoid, drugs (phenytoin). Red flags: hard, fixed, >2 cm, supraclavicular, persistence >4–6 weeks, B symptoms, spleen enlargement.

## B20. Oedema (ch. 17, 49)

Bilateral: heart failure, cirrhosis, nephrotic syndrome, CKD, hypoalbuminaemia/malnutrition, hypothyroidism, drugs (CCBs, NSAIDs, steroids, glitazones), venous insufficiency, pregnancy/pre-eclampsia, idiopathic cyclical. Unilateral: DVT, cellulitis, lymphoedema, venous insufficiency, Baker cyst, compartment syndrome, trauma. Tests: urinalysis (protein), albumin, U&E, LFT, TSH, BNP, ultrasound.

## B21. Back pain (ch. 18, 52, 72)

Can't miss: cauda equina, cord compression, spinal infection, aortic aneurysm/dissection, fracture, malignancy. Common: non-specific mechanical, disc prolapse with radiculopathy, spinal stenosis, facet arthropathy, osteoporotic fracture. Others: inflammatory spondyloarthritis, myeloma, pyelonephritis, renal colic, pancreatitis, referred hip pain.

## B22. Joint pain (ch. 18, 52)

| Pattern | Diagnoses |
|---|---|
| **Monoarthritis, acute hot** | Septic arthritis (aspirate!), gout, pseudogout, haemarthrosis, trauma, reactive |
| **Polyarthritis, symmetric small joints** | RA, viral (parvovirus, hepatitis B), SLE |
| **Oligo/asymmetric, enthesitis** | Spondyloarthritis (psoriatic, reactive, IBD), gout |
| **Non-inflammatory** | Osteoarthritis (DIP/PIP/CMC, knees, hips), fibromyalgia |
| **Systemic** | Lupus, vasculitis, Still's, sarcoid, Lyme, endocarditis, rheumatic fever |

## B23. Limb weakness (ch. 20, 51)

Central: stroke/TIA, MS, tumour, haemorrhage, spinal cord lesion. Peripheral: Guillain–Barré, radiculopathy, mononeuropathy, plexopathy, neuropathy (diabetic, alcohol, B12), myasthenia gravis, myopathy (statins, steroids, inflammatory), motor neuron disease, electrolyte (K, Ca, PO₄), periodic paralysis, botulism, tick paralysis. Functional. Can't miss: stroke, cord compression, GBS (respiratory failure), myasthenic crisis, hypokalaemia.

## B24. Numbness and paraesthesia (ch. 20, 51)

Carpal tunnel, radiculopathy, peripheral neuropathy (diabetes, B12, alcohol, drugs), stroke/TIA, MS, hyperventilation, hypocalcaemia, migraine aura, spinal cord lesion, vasculitis, hypothyroidism.

## B25. Seizure and altered consciousness (ch. 20, 38, 51)

Seizure mimics: syncope, psychogenic non-epileptic seizures, migraine, TIA, hypoglycaemia, movement disorders. Provoked seizure causes: hypoglycaemia, hyponatraemia, hypocalcaemia, alcohol/drug withdrawal, toxicity, head injury, stroke, infection (meningitis/encephalitis), eclampsia. Coma: AEIOU-TIPS (Alcohol, Epilepsy/Electrolytes/Encephalopathy, Insulin, Opiates/Oxygen, Uraemia, Trauma/Temperature, Infection, Psychosis/Poisoning, Stroke/Shock/Seizure).

## B26. Confusion and delirium (ch. 56, 61, 71)

"I WATCH DEATH": Infection, Withdrawal, Acute metabolic, Trauma, CNS pathology, Hypoxia, Deficiencies, Endocrine, Acute vascular, Toxins/drugs, Heavy metals. Dementia vs delirium vs depression (chapter 61). Always check glucose, SpO₂, temperature, medications, urinary retention, constipation, pain.

## B27. Visual loss (ch. 55)

| Onset | Painless | Painful |
|---|---|---|
| **Sudden** | Retinal artery/vein occlusion, retinal detachment, vitreous haemorrhage, stroke, anterior ischaemic optic neuropathy (GCA!) | Acute angle-closure glaucoma, optic neuritis, uveitis, keratitis, orbital cellulitis |
| **Gradual** | Cataract, macular degeneration, open-angle glaucoma, diabetic retinopathy, refractive error | |
| **Transient** | Amaurosis fugax (carotid), migraine aura, papilloedema, TIA | |

## B28. Red eye (ch. 55)

Dangerous: acute glaucoma, keratitis/corneal ulcer, uveitis/iritis, scleritis, endophthalmitis, orbital cellulitis, chemical burn, penetrating injury. Common: viral/bacterial/allergic conjunctivitis, subconjunctival haemorrhage, blepharitis, dry eye. Red flags: reduced acuity, photophobia, pain, fixed pupil, ciliary flush, fluorescein uptake.

## B29. Hearing loss, tinnitus, ear pain (ch. 55)

Conductive: wax, otitis media/externa, perforation, otosclerosis, cholesteatoma. Sensorineural: presbycusis, noise, Ménière's, acoustic neuroma (unilateral), sudden sensorineural hearing loss (emergency: steroids), ototoxic drugs, infection. Unilateral tinnitus or asymmetric hearing loss → MRI.

## B30. Sore throat (ch. 55, 70)

Viral pharyngitis, GAS pharyngitis, EBV, peritonsillar abscess, epiglottitis (airway emergency), retropharyngeal abscess, Lemierre, diphtheria, gonococcal, candidiasis, HIV, GERD, neoplasm.

## B31. Urinary symptoms (ch. 49)

Dysuria: UTI, urethritis (STI), vaginitis, prostatitis, interstitial cystitis, stones. Frequency/nocturia: UTI, diabetes, BPH, overactive bladder, diuretics, heart failure, pregnancy, hypercalcaemia, diabetes insipidus. Haematuria: stones, infection, cancer, glomerulonephritis, trauma, anticoagulation (not sole cause), exercise. Retention: BPH, constipation, drugs, neurological (cauda equina), infection. Incontinence: stress, urge, overflow, functional, neurological.

## B32. Vaginal bleeding and pelvic pain (ch. 48, 57)

Pregnant: ectopic, miscarriage, molar, placenta praevia/abruption, cervical lesions. Non-pregnant: dysfunctional bleeding, fibroids, polyps, adenomyosis, endometrial hyperplasia/cancer, cervical cancer, coagulopathy, thyroid, contraceptives, PCOS. Pelvic pain: PID, endometriosis, ovarian cyst/torsion, appendicitis, UTI, ectopic. Postmenopausal bleeding: endometrial cancer until proven otherwise.

## B33. Scrotal pain and masses (ch. 49)

Torsion (emergency), epididymo-orchitis, trauma, inguinal hernia, hydrocele, varicocele, testicular tumour (painless mass), referred pain (renal colic).

## B34. Skin rash and lesions (ch. 54)

Can't miss: meningococcaemia (non-blanching), SJS/TEN, DRESS, necrotising fasciitis, toxic shock, staphylococcal scalded skin, erythroderma, melanoma. Common: eczema, psoriasis, urticaria, tinea, impetigo, cellulitis, scabies, viral exanthems, contact dermatitis, acne. Systemic: lupus, vasculitis, dermatomyositis, syphilis, Lyme, HIV.

## B35. Anaemia and bleeding disorders (ch. 50, 64)

Anaemia: iron deficiency, chronic disease, B12/folate, haemolysis, marrow failure, thalassaemia, CKD, blood loss. Easy bruising/bleeding: thrombocytopenia (ITP, drugs, marrow), coagulopathy (warfarin, liver, DIC), vWD, vasculitis, scurvy, steroids, senile purpura, abuse.

## B36. Hypotension and shock (ch. 38, 71)

Hypovolaemic, cardiogenic, obstructive (PE, tamponade, tension pneumothorax), distributive (sepsis, anaphylaxis, neurogenic, adrenal crisis, toxins). Chapter 71 gives the algorithm.

## B37. Hypertension (ch. 33, 40)

Primary (essential), secondary: renal parenchymal/renovascular, primary aldosteronism, Cushing's, phaeochromocytoma, thyroid disease, coarctation, OSA, drugs (NSAIDs, steroids, OCP, decongestants, licorice, cocaine), pregnancy-related. Suspect secondary: young age, resistant hypertension, hypokalaemia, abrupt onset, severe or accelerated.

## B38. Anxiety, low mood and psychosis: organic mimics (ch. 56)

Thyroid disease, anaemia, hypoglycaemia, phaeochromocytoma, arrhythmia, PE, caffeine/stimulants, withdrawal, medications (steroids, isotretinoin, levetiracetam, beta-blockers), B12 deficiency, hypercalcaemia, Cushing's, dementia, frontal lobe disease, temporal lobe epilepsy, autoimmune encephalitis, neurosyphilis, HIV, delirium.

## B39. Paediatric presentations (ch. 58–60)

Fever in infants <3 months: serious bacterial infection, UTI, meningitis, viral infection (always treat as emergency). Respiratory distress: bronchiolitis, croup, asthma, pneumonia, foreign body, epiglottitis, heart failure. Vomiting: gastroenteritis, pyloric stenosis, malrotation (bilious), intussusception, UTI, DKA, raised ICP. Limp: transient synovitis, septic arthritis, Perthes, SUFE, fracture, leukaemia. Rash and fever: viral, scarlet fever, Kawasaki, measles, meningococcal. Abdominal pain: appendicitis, mesenteric adenitis, constipation, UTI, torsion.

## B40. Older adult presentations (ch. 61)

Falls, confusion, functional decline, incontinence, weight loss, dizziness: always consider infection (atypical), medication effects, dehydration, electrolytes, anaemia, heart failure/arrhythmia, stroke, subdural, malignancy, depression, dementia, pain, constipation/retention, vision/hearing deficits, social neglect/abuse.

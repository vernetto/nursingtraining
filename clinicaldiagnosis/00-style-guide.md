# Style Guide — Clinical Diagnosis Manual

- **Reader:** medical and nursing students, junior doctors, and clinicians in any setting, including low-resource ones.
- **Language:** English, plain and direct. Define jargon on first use.
- **Chapter structure:** Learning objectives → Core content (numbered sections) → Worked cases → Common pitfalls → Key points → Self-assessment questions.
- **Cases:** Each chapter has at least three worked cases, with realistic numbers. Patients are fictional composites.
- **Units:** SI first, conventional units in brackets where they differ (e.g. glucose 5.5 mmol/L [99 mg/dL]).
- **Numbers:** Thresholds, scores and reference values reflect widely used guidance but must be verified against current local guidelines before clinical use.
- **Tone:** Teach reasoning, not recipes. Explain *why*, then *what*.
